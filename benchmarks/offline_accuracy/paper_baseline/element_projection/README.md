# Elemental constraint projection

Responsibility: a declared algebraic predictor correction, not learning or an
accuracy certificate. Removing conservation defects can still damage species.
No clipping, endpoint normalization, reference-dependent routing or integration.

`gradient_probe.run --experiment EXP-20261013-element-projection --project <root>
--output <new-run>` discovers; add `--execute` for one sequential admitted GPU
inference experiment. JSON owns arms, fixed rows, weights and numerical fallback.

Dependencies: existing diagnostic controller/row staging -> guarded state-only
worker -> frozen base and FP64 SVD. Element mass fractions come from the pinned
mechanism in trusted preparation. No labels, mechanism, secrets, home or network
are mounted for prediction. No coefficients are fitted. Outputs: full signed
predictions, fallback masks, timing and protected/independent recount.
Production has no dependency on this module.

Verify with `python -m pytest tests/test_element_projection.py -q`. Expected:
constant constraints, weighted leastnorm, explicit rank fallback and no hidden
clipping tests pass. Run `element_projection.review --project <root> --run <run>`
as a module for full scores and independently reconstructed CPU formula samples.
