The DeepFlame-style call path

DeepFlame reuses one Cantera reactor and network object, but each CFD cell supplies a new initial thermochemical state. The essential loop is: 

gas.setState_TPY(T_cell, P_cell, Y_cell);
reactor.syncState();
network.advance(delta_t);
gas.getMassFractions(Y_next);
network.setInitialTime(0.0);

Calling syncState() after changing the gas state makes the network reinitialize its integrator. Reusing C++ objects avoids repeated construction, but the next cell normally cannot reuse the previous cell's BDF history, Newton state, or Jacobian factorization.

What advance() does

ReactorNet::advance(t_out) is an adaptive implicit integration request, not a single update from the initial state to the output state. Cantera 2.6 delegates it to CVodesIntegrator::integrate(t_out), which calls SUNDIALS CVODES with CV_NORMAL mode. 

advance(target_time):
    initialize_or_reinitialize_solver()

    while CVODES has not produced the requested output:
        choose internal step size h and BDF order q
        predict the state at the new internal time

        repeat Newton correction:
            evaluate ReactorNet RHS f(t, y)
            refresh the Jacobian when needed
            set up and solve the implicit linear system
            correct the candidate state

        estimate the local integration error

        if error test fails:
            reject the step and reduce h
        else:
            accept the step and adapt h and q

    return/interpolate the solution at target_time
    copy the solution into the reactor and gas phase

For the current frozen-energy reactor, the principal physical equations are the species equations:

dYk/dt = Wk omega_dotk / rho

The reactor energy equation is disabled, so temperature is fixed during the chemistry call. The CFD solver handles the coupled energy update outside this reactor integration.

Why the solve is implicit

A first-order implicit step illustrates the structure. The unknown next state appears inside the chemistry function:

yn+1 = yn + h f(tn+1, yn+1)

CVODES therefore solves the nonlinear residual:

F(yn+1) = yn+1 - yn - h f(tn+1, yn+1) = 0

A Newton correction has the simplified form:

(I - gamma J) delta_y = -F,    J = df/dy,    y ← y + delta_y

Higher-order BDF methods retain the same core difficulty: each accepted internal time step requires a nonlinear solve, and each nonlinear solve may require several chemistry and Jacobian evaluations.

Error control and rejected steps

CVODES scales each state error with the configured absolute and relative tolerances. A simplified component scale is:

scalei = atol + rtol |yi|

The candidate step is accepted only when a weighted norm satisfies:

norm(errori / scalei) ≤ 1

A failed test discards the candidate, reduces the internal step size, and repeats part of the nonlinear solve. This is particularly relevant for combustion because trace-species mass fractions span many orders of magnitude. Raw err_test_fails, internal step sizes, and nonlinear convergence failures are therefore valuable diagnostics for both CVODES and neural-surrogate comparisons.

Why CVodeGet* statistics are hidden in Cantera 2.6

SUNDIALS exposes the desired optional outputs through C functions that all require the private CVODES memory pointer: 

CVodeGetNumSteps(cvode_mem, &steps);
CVodeGetNumRhsEvals(cvode_mem, &rhs_evals);
CVodeGetNumErrTestFails(cvode_mem, &err_test_fails);
CVodeGetNonlinSolvStats(cvode_mem, &nonlinear_iters, &nonlinear_fails);
CVodeGetNumJacEvals(cvode_mem, &jac_evals);
CVodeGetNumLinRhsEvals(cvode_mem, &linear_rhs_evals);
CVodeGetNumLinSolvSetups(cvode_mem, &linear_setups);
CVodeGetLastStep(cvode_mem, &last_h);
CVodeGetCurrentStep(cvode_mem, &next_h);
CVodeGetCurrentTime(cvode_mem, &internal_time);

In Cantera 2.6, CVodesIntegrator::m_cvode_mem is private. The public abstract Integrator API exposes only a small subset, including nEvals() and lastOrder(). The existing nEvals() implementation simply calls CVodeGetNumRhsEvals(m_cvode_mem, ...). External application code cannot call the other functions because it cannot obtain the memory pointer.

Cantera 3.2 solves this at the wrapper level with CVodesIntegrator::solverStats(), which calls the SUNDIALS functions internally and returns named statistics. This implementation is the appropriate reference for a 2.6 backport.

Alternative routes

A. Header-only memory accessor

Add an inline void* cvodeMemory() accessor to the 2.6 header and call CVodeGet* from the harness. It does not change object layout, but it exposes private implementation details and depends on an exactly matching header/library pair. Useful for a short probe, not the preferred persistent interface.

B. Upgrade to Cantera 3.2

Use the native solverStats() API. This is clean for DFODE-kit, but it does not exactly profile the current DeepFlame Cantera 2.6 binary and may change solver behavior and performance.

C. CV_ONE_STEP trace mode

Patch a diagnostic integrator loop to call CVODES one accepted step at a time and query counters after every step. This yields stepwise history, but it changes the calling path and adds substantial overhead. Keep it separate from the baseline timing mode.

Avoid: #define private public, object-layout reinterpretation, or editing Conda headers without rebuilding against a matching copy. These methods are fragile and make benchmark provenance difficult to defend.

Implicit Chemistry Integration Primer: Backward Euler and Radau IIA

This section explains the numerical methods behind the proposed neural-predictor and implicit-corrector experiment. The neural network is not required to produce the final accepted state. It supplies an initial guess, while a physical implicit solver corrects that guess to a specified residual tolerance.

1. The chemistry ODE

Write the thermochemical state as

\[ x(t) = [Y_1,\ldots,Y_{N_s},T]. \]

The chemical mechanism defines its time derivative:

\[ \frac{dx}{dt}=f(x). \]

Here, \(f(x)\) contains species production rates and, for an adiabatic reactor, the temperature source term. In a frozen-temperature DeepFlame chemistry call, \(x\) contains the species mass fractions while \(T\) and \(P\) are fixed parameters. The time-integration problem is to calculate \(x_{n+1}=x(t_n+\Delta t)\) from the known state \(x_n=x(t_n)\).

2. Forward Euler: use the current reaction rate

The simplest update is

\[ x_{n+1}=x_n+\Delta t\,f(x_n). \]

This is an explicit method because every quantity on the right-hand side is known. Consider one irreversible reaction,

\[ A\rightarrow B, \qquad \frac{dY_A}{dt}=-kY_A. \]

Forward Euler gives

\[ Y_{A,n+1}=Y_{A,n}(1-k\Delta t). \]

If \(k\Delta t=100\), then

\[ Y_{A,n+1}=-99Y_{A,n}, \]

which is negative and unstable. Fast reactions therefore force explicit methods to use very small timesteps even when the CFD timestep is much larger.

3. Backward Euler: make the future state self-consistent

Backward Euler evaluates the reaction rate at the unknown future state:

\[ x_{n+1}=x_n+\Delta t\,f(x_{n+1}). \]

For the same decay reaction,

\[ Y_{A,n+1}=Y_{A,n}-k\Delta t\,Y_{A,n+1}, \]

so

\[ Y_{A,n+1}=\frac{Y_{A,n}}{1+k\Delta t}. \]

At \(k\Delta t=100\),

\[ Y_{A,n+1}=\frac{Y_{A,n}}{101}>0. \]

The exact result is \(Y_{A,n}e^{-100}\), which is almost zero. Backward Euler is not exact, but it remains bounded and damps the unresolved fast mode instead of making it explode.

Stability is not accuracy. A stable method does not explode. An accurate method closely follows the true trajectory. Backward Euler is very stable but only first-order accurate, so a large timestep may over-damp or smear the chemistry.

4. Newton iteration solves the implicit equation

Define the backward-Euler residual

\[ G(x)=x-x_n-\Delta t\,f(x). \]

The desired future state is a root:

\[ G(x_{n+1})=0. \]

Detailed chemical source terms are nonlinear, so this root is normally found iteratively. Starting from a guess \(x^{(0)}\), Newton's method solves

\[ \left[I-\Delta t\,J_f\!\left(x^{(k)}\right)\right] \delta^{(k)} =-G\!\left(x^{(k)}\right), \]

and updates

\[ x^{(k+1)}=x^{(k)}+\lambda_k\delta^{(k)}, \qquad 0<\lambda_k\leq1. \]

The chemical Jacobian is

\[ J_f=\frac{\partial f}{\partial x}. \]

It measures how every source term changes when every species or temperature changes. The damping factor \(\lambda_k\) can prevent unsafe Newton updates, including steps that move species deeply into negative values.

5. The neural network supplies only the initial guess

A conventional initialization is often

\[ x^{(0)}=x_n. \]

The hybrid initialization is

\[ x^{(0)}=\Phi_\theta(x_n,\Delta t), \]

where \(\Phi_\theta\) is a trained DFODE interval model. Newton still solves the physical residual. If the network begins closer to the root, fewer nonlinear iterations may be required. If its proposal is invalid or has a worse residual than the conventional guess, the solver rejects it.

6. Why Backward Euler is only the first experiment

Backward Euler describes the whole interval using one derivative evaluated at its endpoint:

\[ x_{n+1}=x_n+\Delta t\,f(x_{n+1}). \]

It is ideal for testing whether a neural prediction improves Newton initialization, but its first-order discretization can be inaccurate at large \(\Delta t\). A useful production candidate should sample the trajectory inside the interval while retaining strong stiff stability.

7. Runge-Kutta stages represent points inside the timestep

Introduce stage states \(Z_1,\ldots,Z_s\). Each stage approximates the chemical state at a selected point inside the interval. A general implicit Runge-Kutta method satisfies

\[ Z_i=x_n+\Delta t\sum_{j=1}^{s}a_{ij}f(Z_j), \qquad i=1,\ldots,s, \]

and computes the endpoint from

\[ x_{n+1}=x_n+\Delta t\sum_{j=1}^{s}b_jf(Z_j). \]

The coefficients \(a_{ij}\), \(b_j\), and stage locations \(c_i\) define the method. Because the stage equations depend on one another, all stage states are solved together.

8. Radau IIA

Radau IIA is a particular implicit Runge-Kutta collocation family. Its final stage lies at the end of the timestep, and the method is L-stable and stiffly accurate. An \(s\)-stage Radau IIA method has order \(2s-1\).

Stages Order Interpretation
1 1 Backward Euler
2 3 Recommended first higher-order hybrid
3 5 More accurate, with a larger coupled solve

9. Two-stage Radau IIA equations

The two stage locations are

\[ c_1=\frac13, \qquad c_2=1. \]

Thus, \(Z_1\) approximates a state about one-third through the interval and \(Z_2\) approximates the endpoint. Their coupled equations are

\[ Z_1=x_n+\Delta t \left[ \frac{5}{12}f(Z_1)-\frac{1}{12}f(Z_2) \right], \] \[ Z_2=x_n+\Delta t \left[ \frac34 f(Z_1)+\frac14 f(Z_2) \right]. \]

Because the method is stiffly accurate,

\[ x_{n+1}=Z_2. \]

The negative coefficient in the first equation is part of the high-order collocation formula. It does not represent a negative physical timestep.

10. Collocation interpretation

Imagine fitting a smooth polynomial path \(p(t)\) across the timestep. Radau IIA requires the path to begin at the known state,

\[ p(t_n)=x_n, \]

and requires its slope to agree with the chemical ODE at every stage:

\[ p'\!\left(t_n+c_i\Delta t\right) =f\!\left(p(t_n+c_i\Delta t)\right). \]

In simple terms, Radau IIA finds a smooth path whose slope agrees with the chemical kinetics at carefully selected points inside the interval.

11. Newton system for all Radau stages

For each stage, define

\[ R_i(Z)=Z_i-x_n-\Delta t\sum_{j=1}^{s}a_{ij}f(Z_j). \]

All stage residuals must vanish:

\[ R(Z)=0. \]

The block Jacobian used by Newton is

\[ \frac{\partial R_i}{\partial Z_j} =\delta_{ij}I-\Delta t\,a_{ij}J_f(Z_j). \]

In compact form, under a common-Jacobian approximation,

\[ \left[I_s\otimes I-\Delta t\,A\otimes J_f\right]\Delta Z =-R(Z). \]

For a chemistry state with ten variables, a two-stage method has about twenty coupled stage unknowns. The larger linear system is the cost of obtaining higher order while preserving strong stiff stability.

12. DFODE initialization of the Radau stages

A simple conventional stage guess is

\[ Z_1^{(0)}=x_n, \qquad Z_2^{(0)}=x_n. \]

The variable-timestep DFODE model can instead provide

\[ Z_1^{(0)}= \Phi_\theta\!\left(x_n,\frac13\Delta t\right), \] \[ Z_2^{(0)}= \Phi_\theta(x_n,\Delta t). \]

Cantera supplies the physical source terms \(f(Z_1)\) and \(f(Z_2)\), and damped Newton corrects the two guesses until the Radau residual meets the requested tolerance.

13. Why this avoids the current semigroup failure

The unstable neural free rollout has the form

\[ \Phi_{\Delta t_2} \!\left(\Phi_{\Delta t_1}(x_n)\right). \]

The second network call receives an imperfect network prediction, which may lie outside the training manifold. Radau initialization instead evaluates

\[ \Phi_\theta(x_n,\Delta t/3) \quad\text{and}\quad \Phi_\theta(x_n,\Delta t). \]

Both calls start from the same true state \(x_n\). No network prediction is fed back into another network call. The physical Radau equations then couple and correct the proposed stages.

14. L-stability and fast chemical modes

For the fast-decay test equation

\[ \frac{dy}{dt}=-\lambda y, \qquad \lambda>0, \]

a numerical method can be written as

\[ y_{n+1}=R(\lambda\Delta t)y_n, \]

where \(R\) is the amplification factor. An L-stable method satisfies

\[ R(\lambda\Delta t)\rightarrow0 \qquad\text{as}\qquad \lambda\Delta t\rightarrow\infty. \]

Thus, unresolved fast modes are driven toward zero rather than oscillating or growing. Backward Euler and every Radau IIA method are L-stable, which makes them natural candidates for stiff chemical kinetics.

15. What Newton correction does and does not guarantee

Newton correction enforces the selected discrete equations:

\[ \lVert R(Z)\rVert < \text{nonlinear solver tolerance}. \]

It does not make the discrete Radau solution identical to the exact continuous trajectory. The total numerical error contains two conceptually different parts:

\[ \text{total error} =\text{time-discretization error} +\text{nonlinear-solve error}. \]

Newton reduces the nonlinear-solve error. Moving from backward Euler to two-stage or three-stage Radau IIA reduces the time-discretization error. The corrected solution must therefore still be compared with a high-accuracy CVODE reference.

16. Practical DFODE-kit roles

Pure DFODE Yes No Maximum speed with greater reliability risk

The first implementation should use backward Euler because its residual and Newton behavior are easy to inspect. If neural initialization substantially reduces iterations without increasing failures, the main scientific experiment should move to two-stage Radau IIA.
