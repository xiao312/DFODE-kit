Solver-Inspired Latent Substepping for Combustion Chemistry Models

The central problem is not only conservation. Hard stoichiometric layers can already preserve atom and mass balance. The hard part is learning the integrated chemical flow over variable CFD time intervals without blindly trusting the initial-state reaction direction.

1. Why one-shot prediction is difficult

A stiff implicit ODE solver does not take a large CFD chemistry interval as one blind jump. It internally subdivides time, repeatedly recomputes rates, Jacobians, thermodynamics, and error estimates, then adapts step size/order. 

CFD asks:      x(t) -> x(t + dt_CFD)
CVODE does:    x(t) -> small step -> recompute -> small step -> ... -> x(t + dt_CFD)
Current model: x(t), dt_CFD -> x(t + dt_CFD)

The affinity-gated experiment exposed this: start-state chemical potential affinity is a good local direction prior, but for long intervals complex mechanisms can cross equilibrium surfaces or switch dominant pathways.

Working hypothesis: the next model should behave like a cheap learned integrator, not only like a one-shot regressor.

2. Model architectures that support internal learned steps

A. Shared-weight residual latent time-stepper

Best first implementation. A residual block is used as a reusable latent time-advance operator. 

z0 = Encoder(x_t)
for k in 1..K:
    z = z + StepNet(z, log(dt/K))
x_next = DecoderOrStoichUpdate(z)

Why: cheap, easy to train, supports K=1,2,4,8, and directly supports semigroup tests.

B. Learned Runge-Kutta style stepper

A staged model predicts intermediate latent slopes/states before combining them. 

k1 = f(z)
k2 = f(z + a21*k1)
z_next = z + b1*k1 + b2*k2

Why: more solver-like; intermediate stages can represent changing reaction direction.

C. Latent Neural ODE

Learn dz/dt = f_theta(z,t) and integrate in latent space.

Why useful: arbitrary time gaps are natural.

Why not first: adaptive ODE solves during inference may reintroduce solver overhead.

D. Deep equilibrium / implicit layer

Solve a learned fixed point z* = F_theta(z*, input), conceptually similar to an implicit update.

Why useful: implicit-style stability.

Why not first: fixed-point/root-finding iterations can be expensive for CFD.

Diffusion and flow matching

These are not the best first route. The chemistry map is mostly deterministic: 

x_t, dt -> x_{t+dt}

Diffusion-style inference typically requires repeated denoising steps. That conflicts with CFD speed unless later used as a low-step consistency/uncertainty model.

3. What to borrow from implicit ODE solvers

Solver idea Learned analogue Why it matters
Adaptive substepping K = StepController(x_t, dt) or a rule by dt bin Avoids forcing one model jump to cover all chemistry timescales.
Predictor-corrector z_pred = Predictor(...), then z_corr = Corrector(...) Uses future/intermediate information rather than only start-state rates or affinity.
Error estimation Compare Phi_dt(x) against Phi_dt/2(Phi_dt/2(x)) Gives a learned local consistency/confidence signal.
Implicit stability Bounded residual updates, contraction near equilibrium, learned corrector iterations Prevents large unstable jumps in stiff or near-equilibrium regions.
Physical invariants Apply delta_Y = (W*S) @ xi at every internal substep Preserves atom and mass conservation throughout the learned integration path.

4. Semigroup consistency is the key training signal

For autonomous time evolution, the flow map should satisfy: 

Phi_{dt1 + dt2}(x) ~= Phi_{dt2}(Phi_{dt1}(x))

The current interval model performs reasonably for one-shot evaluation on true data-manifold states, but fails free two-step composition. That means it learned interpolation on valid starts, not a stable flow.

A practical consistency loss: 

one = model(x, dt)
half = model(x, dt / 2)
two = model(half, dt / 2)

L_semigroup = error(one, two)

This is both physically meaningful and directly connected to adaptive step-size logic.

5. Recommended next implementation

Implement a LatentSubstepStoichIntervalModel. Keep the current hard stoichiometric update and signed-power scaling, but replace one-shot latent decoding with a shared internal latent stepper. 

Input:
    x_t = [T, P, Y]
    dt

z = Encoder(normalized(x_t))
Y = Y_t  # float64 physical species

for k in 1..K:
    h = dt / K
    z = z + GatedStepNet(z, normalized(log(h)))
    raw_xi_k = FluxHead(z, normalized(log(h)))
    xi_k = signed_power_inverse(raw_xi_k, alpha=0.1, scale_by_alpha=True)
    Y = Y + xi_k @ (W*S).T

TP_next = TPHead(z)
x_next = [TP_next, Y]

Initial ablations

  • K=1: should match or approximate current baseline.
  • K=2: first learned substep test.
  • K=4: likely best speed/accuracy tradeoff.
  • K=8: stress test for long intervals.
  • Rule-based adaptive K by dt bin.

Training loss

L = endpoint_loss
  + 0.1 * delta_Y_loss
  + lambda_semigroup * one_vs_two_half_consistency

Evaluation

  • Per-dt-bin species MAE, RMSE, R2, and SSPI.
  • Negative mass-fraction rate.
  • Mass and element residuals.
  • One-step vs two-half-step consistency.
  • Free two-step explosion rate.
  • Runtime per sample versus current one-shot baseline.

6. Role of chemical potential after this result

Chemical potential should not be discarded. The affinity experiment showed that hard start-state direction is too rigid for complex long-dt intervals, but chemical potential is still valuable as:

  • an input feature for local thermodynamic state,
  • an equilibrium/proximity signal,
  • a stability gate near equilibrium,
  • a bias for forward/reverse competition,
  • a diagnostic for whether predicted substeps follow thermodynamic descent.

Better formulation: 

network predicts interval/substep dynamics
affinity biases or regularizes dynamics
affinity does not hard-lock the whole interval direction from x_t
